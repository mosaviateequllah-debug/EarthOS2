# EarthOS v1.2 — Global UX foundation

## Delivered
- New premium visual layer with deeper planetary palette, improved panel hierarchy, hover/focus states and touch-friendly controls.
- Mobile off-canvas navigation with Escape/backdrop close behavior and accessible expanded state.
- Live localized date display.
- PWA manifest and conservative service-worker cache for the static application shell. API and health endpoints are excluded from cache.
- Baseline reverse-proxy security headers and centralized API version.

## Retained
- Existing Persian/English interface and RTL/LTR switching.
- Existing EarthOS pages and project identity.
- NASA POWER daily point integration and source/uncertainty messaging.
- Existing local-only field report workflow.

## Not claimed as implemented
Authentication, cloud report persistence, operational AI models, MODIS/GLDAS/GRACE-FO/SWOT pipelines, drought forecasts, automated alerts, carbon credits, insurance, and global monitoring are not delivered by this release. They remain roadmap items pending data engineering, scientific validation, security and operational infrastructure.
